# Fraud-Sight-UPI-Fraud-Detection
Fraud-Sight — Hybrid UPI Fraud Detection System
A complete end-to-end Machine Learning project for detecting Unified Payments Interface (UPI) fraud using a Hybrid ML Model combining Supervised + Unsupervised learning.

This project includes:

Full EDA

Multiple ML models (Random Forest, XGBoost, Autoencoder)

Hybrid Model (RF + IsolationForest + Logistic Regression Meta Layer)

Streamlit Dashboard for real-time scoring

Power BI Dashboard for business insights

Complete repository with notebooks, models, reports, and app

🚀 Tech Stack
Layer	Tools Used
Data Processing	Python, Pandas, NumPy
Visualization	Matplotlib, Seaborn, Power BI
ML Models	RandomForest, IsolationForest, XGBoost, Autoencoder
Meta-Model	Logistic Regression
Deployment	Streamlit
Packaging	Joblib

📊 Project Highlights
🔍 1. Problem
UPI fraud is rare (<0.03%), making ML detection extremely challenging.
This project solves imbalanced data using a hybrid supervised + unsupervised approach.

🤖 2. Models Trained
Rule-based baseline

Random Forest (Supervised)

XGBoost (Supervised)

Autoencoder (Unsupervised Reconstruction)

Isolation Forest (Unsupervised Anomaly Detection)

Hybrid Model → Combines RF Probability + ISO Score

🧠 3. Why Hybrid Model?
Because it captures:

Pattern-based fraud (supervised)

Never-seen anomalies (unsupervised)

💡 This outperforms all other models.
